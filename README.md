# ხინკლის დუელი

ორი მოთამაშის ონლაინ თამაში. ერთი ადამიანი ქმნის ოთახს და მეგობარს ბმულს უგზავნის, მეგობარი ბმულს ხსნის და თამაში იწყება. ბრაუზერში მუშაობს, ტელეფონზეც და კომპიუტერზეც. ხმები თავად თამაშშია, ცალკე ფაილები არ სჭირდება.

## ფაილები (საქაღალდეები არ არის, ყველაფერი ერთ დონეზეა)

- `server.js` არის სერვერი: ინახავს ოთახებს და თავად წყვეტს, ვის რა სვლა გამოუვიდა.
- `index.html`, `style.css`, `app.js`, `rules.js`, `manifest.webmanifest`, `icon.svg`, `bg.svg` (ქართული ფონი), `tile.svg` (ბოლნისური ჯვრების ორნამენტი) არის ის, რასაც მოთამაშე ხედავს.
- `package.json` ეუბნება სერვერს, რა ბიბლიოთეკა სჭირდება.
- `render.yaml` არის Render-ის პარამეტრები (არასავალდებულო).
- `test.js` არის ავტომატური შემოწმება (არასავალდებულო).

**მნიშვნელოვანია:** ატვირთვისას ყველა ფაილი უნდა მოხვდეს საცავის მთავარ გვერდზე. თუ რომელიმე აკლია, სერვერი ჩაირთვება და ლოგში დაწერს, რომელი ფაილი აკლია.

## ძველი ფილმების კლიპები (არასავალდებულო)

თამაშს ჩაშენებული აქვს თავისი კინო-სცენები (ფირის ეფექტი, ბორჯღალი, კოშკები, ცეცხლი, წარწერები), ამიტომ კლიპების გარეშეც სრულად მუშაობს. თუ გინდა, რომ რეალური მოკლე ფრაგმენტი (დაახლოებით 2 წამი) გამოჩნდეს, ფაილები უბრალოდ ატვირთე საცავში იმავე ადგილას, სადაც დანარჩენები არიან. დასახელება განსაზღვრავს, სად გამოჩნდება:

- `clip-roll-1.mp4`, `clip-roll-2.mp4` და ა.შ. გამოჩნდება კამათლის გაგორებისას
- `clip-win-1.mp4` და ა.შ. გამოჩნდება რაუნდის ან თამაშის მოგებისას
- `clip-lose-1.mp4` და ა.შ. გამოჩნდება წაგებისას

ფორმატი: `.mp4`, `.webm` ან `.gif`; თითო ფაილი არაუმეტეს 8 მბ-ისა. სახელში მხოლოდ ლათინური ასოები, ციფრები და ტირე. სხვა ცვლილება კოდში საჭირო არ არის, Render ახალ ფაილს თავისით აიღებს და თამაში კლიპს თავად აღმოაჩენს.

**ავტორის უფლებები:** ატვირთე მხოლოდ ისეთი კადრები, რომლებზეც გაქვს უფლება: საკუთარი გადაღებული, საჯარო დომენის (ძველი უცხოური მუნჯი ფილმები, მაგალითად, archive.org-ზე, ყოველთვის შეამოწმე კონკრეტული ფილმის სტატუსი) ან ნებართვით აღებული. ქართული საბჭოთა ფილმების უმეტესობა დაცულია, მათი ნაწყვეტები უნებართვოდ საჯარო თამაშში არ უნდა გამოიყენო.

## გამოქვეყნება ინტერნეტში (Render, უფასო გეგმა)

ეს ნაბიჯები კომპიუტერიდან უფრო ადვილია. გვერდებზე სახელები შეიძლება ოდნავ განსხვავდებოდეს, მაგრამ აზრი იგივეა.

1. **GitHub-ის ანგარიში.** გახსენი github.com და დარეგისტრირდი.
2. **ახალი საცავი.** დააჭირე **New repository**, სახელად დაარქვი `khinkali-duel`, დააჭირე **Create repository**.
3. **ფაილების ატვირთვა.** ამ არქივის ჯერ გახსენი (unzip). საცავის გვერდზე აირჩიე **uploading an existing file**, შემდეგ საქაღალდეში მონიშნე ყველა ფაილი (Ctrl+A ან Cmd+A) და გადაათრიე გვერდზე. შეამოწმე, რომ სიაში ჩანს 13 ფაილი (`.gitignore` ფარულია და არ არის აუცილებელი), და დააჭირე **Commit changes**.
4. **Render.** გახსენი render.com და შედი GitHub-ით. დააჭირე **New**, მერე **Web Service**, აირჩიე `khinkali-duel`.
5. **პარამეტრები.** Language/Runtime: **Node**. Build Command: `npm install`. Start Command: `npm start`. Instance Type: **Free**.
6. დააჭირე **Create Web Service**. რამდენიმე წუთში ზედა მხარეს გამოჩნდება შენი ბმული, მაგალითად `https://khinkali-duel-xxxx.onrender.com`.
7. გახსენი ბმული, დააჭირე „ოთახის შექმნას“ და გაუგზავნე მეგობარს ბმული.

თუ ფაილები უკვე ატვირთე და მხოლოდ რაღაც ცვლის, GitHub-ზე ისევ **Add file**, მერე **Upload files**. იმავე სახელის ფაილები ძველს ანაცვლებს. Render ცვლილებას ავტომატურად იღებს და თავისით თავიდან ქმნის.

ტელეფონზე ბრაუზერის მენიუდან შეგიძლია აირჩიო „მთავარ ეკრანზე დამატება“ და თამაში აპლიკაციასავით გაიხსნება.

## რაც უფასო გეგმაზე უნდა იცოდე

- თუ 15 წუთის განმავლობაში არავინ შედის, სერვერი იძინებს. პირველი გახსნა მერე დაახლოებით ერთ წუთს გრძელდება.
- ოთახები სერვერის მეხსიერებაშია. თუ სერვერი ხელახლა ჩაირთო ან დაიძინა, აქტიური ოთახები იკარგება.
- Render ამბობს, რომ უფასო გეგმა სატესტოა და არა სერიოზული პროდუქტისთვის. ფულიანი გეგმა მოგვიანებით გადავხედოთ, როცა მოთამაშეები გამოჩნდებიან.

## კომპიუტერზე გასაშვებად (არასავალდებულო)

საჭიროა Node.js 18 ან უფრო ახალი.

```
npm install
npm start
```

შემდეგ გახსენი http://localhost:3000. შემოწმების გასაშვებად: `npm test`.
